# Терминал анкетирования для Windows

Локальное приложение с сенсорным интерфейсом и печатью на ленте 80 мм
(также доступна ширина 58 мм). Содержит 7 анкет / 174 вопроса из content.py
предоставленного проекта MAX. Токены, база пользователей и старые результаты
не включены. Интернет при работе не нужен.

## Запуск на Windows

1. Установите Python 3.10+ с python.org, включив Python Launcher или PATH.
2. Распакуйте приложение и дважды нажмите start_windows.bat.
3. Откроется браузер. F11 включает полный экран.
4. Не закрывайте окно Python во время работы. Остановка — Ctrl+C.

Приложение слушает только 127.0.0.1, порт 8765. Если порт занят:
`py -3 app.py --port 8766`. Внешних зависимостей нет.

## Термопринтер 80 мм

1. Установите драйвер производителя и проверьте пробную страницу Windows.
2. В драйвере выберите рулон 80 мм и подходящую длину страницы.
3. После заполнения нажмите «Распечатать результат».
4. В диалоге печати выберите термопринтер, бумагу 80 мм, масштаб 100%,
   поля «Нет», отключите колонтитулы и подтвердите печать.

Ширина содержимого чека — 70 мм. Длина страницы и автоматический отрез
определяются драйвером. На длинных анкетах возможна разбивка на страницы:
настройте длину рулона в драйвере. Печать и отрез требуют проверки на вашей
модели. Текущая версия использует диалог печати; печать без диалога и ESC/POS
не настроены.

## Ответы и результаты

Ответы находятся только в памяти вкладки: нет отправки на сервер, базы или
сохранения в браузере. «Новый посетитель» и «Завершить сеанс» очищают ответы.
После 3 минут бездействия сеанс также очищается; во время диалога печати
таймер приостанавливается. Закрывайте диалог печати после использования.
Бумажные чеки и очередь печати Windows управляются отдельно.

Чек содержит полные вопросы и ответы, число «да», «нет» и пропусков, дату
и время компьютера. Медицинские пороги бота не перенесены: он считает все
ответы «да» одинаково, включая полезные привычки. Для автоматического
заключения нужна проверенная врачом схема оценки. Вопросы сохранены дословно.
Анкета не является диагнозом.

## Разработка

Облачная задача уже изолирована: используйте существующий checkout,
дополнительный Git worktree не нужен.

Запуск из каталога проекта: `python3 app.py --no-browser`.
Проверка сервера: `python3 -m unittest discover -s tests -v`.
Проверка браузера (Playwright и Chromium нужны только для разработки):
`python3 tests/browser_smoke.py` при запущенном сервере на порту 8765.
